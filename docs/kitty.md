# Kitty Keybindings

Kitty is a fast, feature-rich, GPU-based terminal emulator. [find out more](https://sw.kovidgoyal.net/kitty/)

- [My configs](https://github.com/2KAbhishek/dots2k/tree/main/config/kitty)
- [Live keybindings](https://github.com/2KAbhishek/dots2k/tree/main/docs/kitty.md)

| Keybinding                                              | Action                           |
| ------------------------------------------------------- | -------------------------------- |
| <kbd>Ctrl</kbd> + <kbd>Shift + -</kbd>                  | Horizontal split                 |
| <kbd>Ctrl</kbd> + <kbd>Shift + \</kbd>                  | Vertical split                   |
| <kbd>Ctrl</kbd> + <kbd>Shift + Alt + Arrows</kbd>       | Resize split window              |
| <kbd>Ctrl</kbd> + <kbd>Shift + B</kbd>                  | Browse scrollback buffer         |
| <kbd>Ctrl</kbd> + <kbd>Shift + C</kbd>                  | Copy to clipboard                |
| <kbd>Ctrl</kbd> + <kbd>Shift + E</kbd>                  | Open selection in qutebrowser    |
| <kbd>Ctrl</kbd> + <kbd>Shift + Enter</kbd>              | Vertical split                   |
| <kbd>Ctrl</kbd> + <kbd>Shift + H/J/K/L</kbd>            | Navigate splits (Vim keys)       |
| <kbd>Ctrl</kbd> + <kbd>Shift + Left/Right/Up/Down</kbd> | Navigate splits (Arrow keys)     |
| <kbd>Ctrl</kbd> + <kbd>Shift + O</kbd>                  | Open URL with hints              |
| <kbd>Ctrl</kbd> + <kbd>Shift + P</kbd> > <kbd>F</kbd>   | Insert file path hint            |
| <kbd>Ctrl</kbd> + <kbd>Shift + P</kbd> > <kbd>H</kbd>   | Insert git hash hint             |
| <kbd>Ctrl</kbd> + <kbd>Shift + P</kbd> > <kbd>L</kbd>   | Insert line hint                 |
| <kbd>Ctrl</kbd> + <kbd>Shift + P</kbd> > <kbd>U</kbd>   | Open URL hint                    |
| <kbd>Ctrl</kbd> + <kbd>Shift + P</kbd> > <kbd>W</kbd>   | Insert word hint                 |
| <kbd>Ctrl</kbd> + <kbd>Shift + V</kbd>                  | Paste from clipboard             |
| <kbd>Ctrl</kbd> + <kbd>Shift + W</kbd>                  | Close split window               |
| <kbd>Ctrl</kbd> + <kbd>Shift + Z</kbd>                  | Toggle split zoom (stack layout) |
